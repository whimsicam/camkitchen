# CAM Kitchen

Il nutrizionista di CAM: programma alimentare, menù a cicli, spesa, dispensa e ricettario. Web app statica (GitHub Pages), gemella di [CAM Gym](https://github.com/whimsicam/camgym).

- `SPEC.md`: la specifica completa.
- `programma.json`, `alimenti.json`, `preset.json`, `ricette/`: il programma, scritto da Claude.
- `giorni/`, `cicli/`, `alias-utente.json`: i dati di CAM, scritti dall'app.
- `inbox/`: voci della spesa aggiunte con Siri (l'app le importa e le cancella).
- `disegni/`: illustrazioni dei piatti (`disegni-prompt.md` per generarle).
- `design/prototipo.html`: il prototipo approvato, riferimento visivo.
